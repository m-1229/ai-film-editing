# AI 智能剪辑工具

**点一下，AI 自己把片子粗剪完，直接给你能用的成片。**

选好视频 → 点「AI 粗剪」→ 等它跑完 → 拿到成片和一份「精调包」，
然后把精调包丢进剪映 / PR / DaVinci 里做精细调整。整个过程不需要你标记任何东西。

界面是「本地服务 + 独立 App 窗口」：双击桌面图标后会弹出一个没有地址栏的窗口，
用起来和普通桌面软件一样。

## 启动方式

| 方式 | 说明 |
|------|------|
| 桌面「AI 剪辑工具」图标 | **推荐**，双击即开，无黑窗口，约 3 秒出界面 |
| `启动程序.bat` | 后台启动（无控制台），出错信息写入 `运行日志.log` |
| `调试启动.bat` | 带控制台启动，能看到完整报错，排查问题时用 |
| `D:\Python311\python.exe main.py` | 命令行启动 |
| `python main.py analyze <视频路径>` | 纯命令行分析，不打开界面 |

关闭窗口后，后台服务会在约 15 秒内自动退出，不会残留进程。

## 主流程：AI 粗剪

1. 选视频
2. 选力度：**保守 / 标准 / 紧凑**（剪得有多狠）
3. 点「AI 粗剪」
4. 等它跑完：分析 → 决策 → 渲染，一次结束
5. 成片有了，右侧会显示保留/剪掉多少秒

想换力度重剪，直接换档再点一次。**分析结果会缓存复用**，第二次只重新决策和渲染，快很多。

### AI 会剪掉什么

| 类型 | 判断依据 | 处理方式 |
|------|----------|----------|
| 静音 | 音轨低于 -40dB 持续超过阈值 | 两端各留 0.12–0.4 秒气口，只剪中间（不会剪断呼吸） |
| 重复 | 抽样帧相关性 ≥98.5% 且间隔 >3 秒 | 整段剪掉（口误重录、重复镜头） |
| 死时间 | 画面几乎不动 **且** 没有声音 | 保留前 1.5–4 秒让人看清，压掉后面拖时间的部分 |
| 黑场 / 白场 | 整帧方差极低且亮度极端 | 多长都剪（纯废画面） |
| 纯色画面 | 方差极低但亮度正常 | 只在 ≤3 秒时当作转场剪掉，长纯色视为作者有意画面 |

几个刻意的保守设计，避免"剪错"：

- **画面静止不算死时间**。固定机位口播、PPT 讲解时画面本身就不动，只有在同时没声音时才剪。
- **整片都不动就不压**。图片视频、长截图类素材，静止是它的正常形态。
- **静态画面不算重复**。彩条、PPT 这类画面相邻帧本来完全一样，会被误判成"重复镜头"，已剔除。
- **没有音轨就不按静音剪**。全片静音超过 75% 时判定为无音轨，跳过静音剪裁。

每条决策都会在界面上写明「为什么剪」，点开「AI 怎么剪的」能看到全部明细。

## 精调包：拿到市面软件里继续剪

点「导出精调包」，会在成片旁边生成一个文件夹：

```
<名字>_精调包/
├── <名字>_粗剪.mp4        成片，直接能发
├── timeline.edl           剪辑时间线，PR / DaVinci / FCP 可直接导入
├── 剪辑清单.csv            每段从哪到哪 + AI 的剪辑理由（Excel 可直接打开）
└── clips/
    ├── clip_01.mp4        只保留的片段，逐段拖进剪映做精调
    ├── clip_02.mp4
    └── ...
```

`clips` 用 ffmpeg stream copy 切，不重编码所以很快；切完会校验时长，
关键帧对齐偏差超过 0.6 秒的会自动改成精确重编码。

## 手动微调（想改 AI 的判断时）

时间轴上每段剪掉的内容都是一条可编辑的色带：

| 操作 | 效果 |
|------|------|
| 在胶片条上拖动 | 新建一段要剪掉的区间（不需要先跑分析） |
| 拖色带左右边缘 | 微调起点 / 终点 |
| 拖色带中间 | 整段平移，长度不变 |
| 双击色带 | 启用 / 停用，停用后变灰且不参与剪辑 |
| 拖动标尺 | 连续擦洗画面 |
| Delete / Backspace | 删除选中的区间 |
| 右侧列表的勾选框 | 按类型批量启用 / 停用 |

改完后点「按时间轴出片」，就按你改的结果重新渲染。
导出的精调包永远反映当前时间轴状态，不是 AI 最初的结果。

## 环境

- Python 3.11（`D:\Python311`），依赖见 `requirements.txt`
- FFmpeg：由 `imageio-ffmpeg` 自带，在 `bin\ffmpeg.exe` 建了同名硬链接（不额外占空间），
  `utils/ffmpeg_setup.py` 启动时自动接入 PATH
- 界面用系统自带的 Edge / Chrome 以 App 模式打开，无需额外安装

## 接口

本地服务默认跑在 `127.0.0.1:8756`：

| 接口 | 说明 |
|------|------|
| `GET /api/info?path=` | 视频基础信息 |
| `GET /api/filmstrip?path=&count=` | 时间轴胶片条缩略图 |
| `GET /api/video?path=` | 带 Range 的视频流 |
| `POST /api/autocut` | **一键粗剪**（分析 + 决策 + 渲染），入参 `path` / `strength` |
| `POST /api/analyze` | 只分析，不渲染 |
| `POST /api/render` | 按指定区间渲染（手动流程） |
| `POST /api/export-kit` | 导出精调包 |
| `GET /api/job/<id>` | 查询任务进度 / 结果 |
| `POST /api/job/<id>/cancel` | 取消任务 |
| `POST /api/open` | 打开成片或所在文件夹 |
