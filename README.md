# AI 智能剪辑工具

**点一下，AI 自己把片子粗剪完，直接给你能用的成片。**

选题材 → 点「AI 粗剪」→ 等它跑完 → 拿到成片和一份「精调包」，然后把精调包丢进剪映 / PR / DaVinci 里做精细调整。
整个过程不需要你手动标记任何东西：剪掉哪些停顿、哪些重复镜头、哪些「嗯…那个…」的重说，都由它自己判断，并且会写明每一刀的理由。

全程在你自己的电脑上跑，视频不上传。语音转写也是本地的（faster-whisper），不联网。

## 它能干什么

- **AI 粗剪**：一次跑完「分析 → 决策 → 渲染」，直接出成片，三档力度（保守 / 标准 / 紧凑）。
- **口播专项**：一键预设，同时开「剪口头禅 + 开字幕 + 硬切转场 + 音量归一」，一次出片不用跑两遍。
- **语音级剪辑**：本地转写后按内容剪——语气词（嗯/呃/那个/就是）、说错重来、句内重复。
- **字幕**：本地转写自动生成，字号/颜色/描边/底框/逐字点亮可调，支持 SRT 导入导出；烧录和竖屏裁切合并成一次编码。
- **竖屏 9:16**：模糊背景（默认，不切画面）或居中裁切，输出固定 1080×1920。
- **BGM / 变速 / 转场**：9 种转场 + 自动按镜头差挑选，变速不变调，BGM 侧链闪避。
- **精调包**：EDL + CSV 清单 + 分段素材 + SRT，PR / DaVinci / 剪映直接接。
- **轻降噪**：`highpass + afftdn`，只压人声原音轨，不压 BGM。

## 系统要求

| 项 | 要求 |
|---|---|
| Python | **3.10 / 3.11 / 3.12 推荐**（开发环境是 3.11）。3.13 未验证，见下方说明 |
| ffmpeg | 不强制手装——[有三层兜底](#ffmpeg-从哪来)，`pip install` 就够了 |
| 磁盘 | 代码 + 依赖约 **600MB**；字幕模型首次下载 **464MB**；处理视频时还要留出原片 2～3 倍的空间 |
| 内存 | 建议 8GB 以上（1080p 抽帧 + 转写同时跑时峰值约 2～3GB） |
| 系统 | Windows / macOS / Linux 都可以；Windows 上体验最完整（能开无地址栏的独立 App 窗口） |

> Python 3.13 没验证过全链路（主要是 `faster-whisper` → `ctranslate2` 的轮子）。**推荐直接用 3.11。**

## 安装

三平台流程一样，只有激活虚拟环境的命令不同。

```bash
git clone https://github.com/m-1229/ai-film-editing.git
cd ai-film-editing

python -m venv .venv

# Windows (Git Bash / PowerShell / cmd)
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt

python main.py
```

然后在浏览器打开 <http://127.0.0.1:8756>（`python main.py` 会自动帮你打开一个独立窗口）。

依赖体积说明见 `requirements.txt` 里的注释：**不需要 torch，不需要 transformers**，整套装完约 400–600MB。

## 首次运行会发生什么

这一点先说清楚，免得以为程序卡死了：

1. **启动很快**（约 2–3 秒），界面就出来了，能选视频、能预览。
2. **第一次用「字幕」或「口头禅/重说」时，会先下载语音模型。**
   - 模型：`faster-whisper` 的 `small` 档（中英通吃），下载后落在 `models/whisper/`，**磁盘占用约 464MB**。
   - 默认走国内镜像 `hf-mirror.com`（代码里已经设好），国内基本能下动；海外网络慢的话见[常见问题](#常见问题)。
   - 这一段时间进度条只会停在「首次使用，正在下载 small 模型（约 484MB）…」（界面文案按下载量估的，比磁盘占用略大），**没有细粒度百分比，属正常现象**。10M 宽带大概 5–10 分钟。
   - 下载一次就够了，之后离线可用。
3. **第一次转写一部 10 分钟口播，CPU 上要等好几分钟**（接近实时速度）。之后同一部片有缓存，换力度重剪不用重转。
4. 只做普通粗剪（不碰字幕、不剪口头禅）的话，**永远不需要下载模型**。

## ffmpeg 从哪来

`utils/ffmpeg_setup.py` 启动时按这个顺序找，命中即用：

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 项目内 `bin/ffmpeg.exe` | 本机有就把 ffmpeg 放这儿（**该目录不入库**，克隆下来是没有的） |
| 2 | 系统 `PATH` 里的 `ffmpeg` | `winget install ffmpeg` / `brew install ffmpeg` / `apt install ffmpeg` |
| 3 | `imageio-ffmpeg` 自带的二进制 | **`pip install -r requirements.txt` 之后这一层必定可用** |

也就是说：**什么都不做也能跑**，因为第 3 层由 `requirements.txt` 里的 `imageio-ffmpeg` 保证。
想用自己那份（版本更新、带硬件编码）就装到 PATH，或者丢进 `bin/`。

> 小提示：走第 3 层时，启动日志里可能出现一句
> `RuntimeWarning: Couldn't find ffmpeg or avconv - defaulting to ffmpeg` —— 那是因为 imageio 的二进制文件名不叫 `ffmpeg.exe`，pydub 探测时没认出来。程序随后会把正确路径显式塞给 pydub，**功能不受影响，可以忽略**。

```bash
python -c "from backend.server import serve; serve(port=8756, open_browser=False, idle_exit=False)"
```

> 注意 `idle_exit=False`：默认服务端会盯着页面心跳，前端 12 秒没响应就自动退出（正常使用时＝「关窗口＝退程序」）。调试时不加这个参数，服务会在 20 秒后自己关掉。

| 脚本 | 用途 |
|---|---|
| `启动程序.bat` | 后台启动（无控制台窗口），出错信息写入 `运行日志.log` |
| `调试启动.bat` | 带控制台启动，能看到完整报错，排查问题时用 |

## 主流程：AI 粗剪

1. 选视频
2. 选力度：**保守 / 标准 / 紧凑**（剪得有多狠）
3. 点「AI 粗剪」
4. 等它跑完：分析 → 决策 → 渲染，一次结束
5. 成片有了，右侧会显示保留/剪掉多少秒

想换力度重剪，直接换档再点一次。**分析结果会缓存复用**，第二次只重新决策和渲染，快很多。

### AI 会剪掉什么

| 类型 | 判断依据 | 处理方式 |
|------|----------|----------|
| 静音 | 音轨低于 -40dB 持续超过阈值 | 两端各留 0.12–0.4 秒气口，只剪中间（不会剪断呼吸） |
| 重复 | 抽样帧相关性 ≥98.5% 且间隔 >3 秒 | 整段剪掉（口误重录、重复镜头） |
| 死时间 | 画面几乎不动 **且** 没有声音 | 保留前 1.5–4 秒让人看清，压掉后面拖时间的部分 |
| 黑场 / 白场 | 整帧方差极低且亮度极端 | 多长都剪（纯废画面） |
| 纯色画面 | 方差极低但亮度正常 | 只在 ≤3 秒时当作转场剪掉，长纯色视为作者有意画面 |
| 语气词 | 转写后按词表和两侧停顿判断（嗯/呃/那个/就是…） | 只剪「孤立冒出来」的，正常用法不动 |
| 重说 | 同一句说两遍 / 说半句重来 / 句内词组重复 | 取后一遍，剪前一遍 |

几个刻意的保守设计，避免"剪错"：

- **画面静止不算死时间**。固定机位口播、PPT 讲解时画面本身就不动，只有在同时没声音时才剪。
- **整片都不动就不压**。图片视频、长截图类素材，静止是它的正常形态。
- **静态画面不算重复**。彩条、PPT 这类画面相邻帧本来完全一样，会被误判成"重复镜头"，已剔除。
- **没有音轨就不按静音剪**。全片静音超过 75% 时判定为无音轨，跳过静音剪裁。
- **序数词不当重说**。「我们讲第一点 / 我们讲第二点」字面很像，但那是并列内容，剪掉就丢东西了。
- **语音级剪太多就整体不动**。估算要剪掉超过全片 35% 时直接放弃，并提示先核对转写。

每条决策都会在界面上写明「为什么剪」，点开「AI 怎么剪的」能看到全部明细。

## 字幕 / BGM / 变速 / 转场 / 竖屏 / 降噪

右侧「效果」页，或者直接在对话框里说（两条路的参数在后端合并，**文字里提到的以文字为准**）。

- **字幕**：本地转写 → 烧录。字号、位置、描边色、底框、底框透明度、**逐字点亮**都可调；支持 SRT 导入/导出。
  逐字点亮走 libass 原生 `{\kf}`，变速/转场/跨剪切点之后仍然对齐（跨剪切点的词宁可少亮一个也不会亮错）。
- **竖屏 9:16**：`blur`（模糊背景，默认，不切画面）/ `crop`（居中裁切），输出 1080×1920。源片本来就是 9:16 时跳过不重编。
- **BGM**：自带音乐库窗口（拖拽或点选导入，落 `music/`），音量配比、淡入淡出、可选保留/替换原声、侧链闪避。
- **变速**：整体或指定区间，`atempo` 链式处理，音调不变。
- **转场**：9 种（叠化/溶解/黑场/白场/擦除/滑动/圆形/像素/平滑）；默认 `auto`，按接缝画面差挑类型。
- **音量归一**：loudnorm 到 -16 LUFS（口播预设默认开）。
- **轻降噪**：`highpass=f=80` + `afftdn=nr=10:nf=-30`，只压人声原音轨。**口误、呼吸声、咂嘴**这类细杂音靠它压。

> 渲染统一走 ffmpeg 管线（切段 → 拼接 → BGM → 降噪 → 烧字幕 → 换画布，每步独立可定位）。
> 只有当 ffmpeg 完全不可用时才会退回 moviepy 老路径，那条路径做不到竖屏和降噪，会在状态栏说明。

## 精调包：拿到市面软件里继续剪

点「导出精调包」，会在 `projects/output/` 里生成一个文件夹，名字是「成片名 + `_精调包`」：

```
<成片名>_精调包/
├── <成片名>.mp4           成片，直接能发
├── timeline.edl           剪辑时间线，PR / DaVinci / FCP 可直接导入
├── 剪辑清单.csv            每段从哪到哪 + AI 的剪辑理由（Excel 可直接打开）
├── 字幕.srt               有字幕时才有，已映射到成片时间
└── clips/
    ├── clip_01.mp4        只保留的片段，逐段拖进剪映做精调
    ├── clip_02.mp4
    └── ...
```

`clips` 用 ffmpeg stream copy 切，不重编码所以很快；切完会校验时长，关键帧对齐偏差超过 0.6 秒的会自动改成精确重编码。
`clips` 始终是原分辨率原音轨，竖屏/降噪/字幕**不污染**它，拿回剪映随时能改。

## 手动微调（想改 AI 的判断时）

时间轴上每段剪掉的内容都是一条可编辑的色带：

| 操作 | 效果 |
|------|------|
| 在胶片条上拖动 | 新建一段要剪掉的区间（不需要先跑分析） |
| 拖色带左右边缘 | 微调起点 / 终点 |
| 拖色带中间 | 整段平移，长度不变 |
| 双击色带 | 启用 / 停用，停用后变灰且不参与剪辑 |
| 拖动标尺 | 连续擦洗画面 |
| Delete / Backspace | 删除选中的区间 |
| 右侧列表的勾选框 | 按类型批量启用 / 停用 |

改完后点「按时间轴出片」，就按你改的结果重新渲染。
导出的精调包永远反映当前时间轴状态，不是 AI 最初的结果。

## 对话式剪辑（可选，需要大模型 API）

界面右下角的对话框可以直接说人话：「把废话剪掉，加字幕，竖屏」「紧凑一点，配个轻快的 BGM」。
**纯规则解析已经能覆盖大部分常用说法，不配大模型也能用**；配了理解力更好，能处理更绕的表述。

配置方式（二选一，环境变量优先）：

```bash
# 环境变量
export LLM_BASE_URL="https://api.openai.com/v1"    # 或任何 OpenAI 兼容网关
export LLM_API_KEY="sk-..."
export LLM_MODEL="gpt-4o-mini"
```

或者填到项目根目录的 `config.json`（界面上也有设置入口，会自动写这个文件）：

```json
{ "llm": { "base_url": "https://api.openai.com/v1", "api_key": "sk-...", "model": "gpt-4o-mini" } }
```

> `config.json` 里有你的 key，**已在 `.gitignore` 里排除，别手动提交它**。没有 key 时对话解析自动退回本地规则，接口不会报错。
>
> **隐私说明**：不开大模型时全部本地跑，一个字节都不出网。
> 开了大模型，只有「你说的那句话 + 视频时长这类基本信息」会发给那个 API，**视频文件和音频都不上传**。

## 常见问题

**Q：没装 ffmpeg 会怎样？**
不会怎样，照常跑。`requirements.txt` 里的 `imageio-ffmpeg` 会提供一份（见 [ffmpeg 从哪来](#ffmpeg-从哪来)）。
只有一种情况会有影响：你想用硬件编码 / 更新的 ffmpeg 版本，那就自己装一份到 PATH。

想知道当前实际用的是哪一份，跑这一行：

```bash
python -c "from utils.ffmpeg_setup import find_ffmpeg; print(find_ffmpeg())"
```

**Q：日志里那句 `Couldn't find ffmpeg or avconv` 是报错吗？**
不是。走 imageio-ffmpeg 那一层时 pydub 探测不到同名的 `ffmpeg.exe` 会先警告一句，程序紧接着就把正确路径显式塞给它了。功能正常，可以忽略。

**Q：模型下载很慢、或者下载失败怎么办？**
代码默认走国内镜像 `hf-mirror.com`。海外网络反而可能更慢，那就覆盖掉它：

```bash
# Windows PowerShell
$env:HF_ENDPOINT="https://huggingface.co"
# macOS / Linux
export HF_ENDPOINT="https://huggingface.co"
python main.py
```

实在下不动就手动下载后放到 `models/whisper/`，目录结构保持 HuggingFace 缓存的样子（`models--Systran--faster-whisper-small/snapshots/<hash>/model.bin`）。
删掉 `models/whisper/` 整个目录再重开，等于从头重下。

**Q：端口 8756 被占用？**
`python main.py web 9000` 换一个端口即可。
如果提示「服务已在运行」，说明上一次的窗口还活着，程序会直接把那个窗口拉到前面；要彻底清掉就关掉所有相关窗口，或去任务管理器结束残留的 `python.exe`。

**Q：Windows 上 `ModuleNotFoundError: No module named 'flask'`？**
九成是 `python` 指到了另一个 Python（常见是微软商店的 3.13），跟装依赖的那个不是同一个。确认一下：

```bash
python -c "import sys; print(sys.executable)"
pip -V
```

两个路径的目录必须是同一个，并且都在 `.venv` 里。最省事的做法：激活 `.venv` 之后一律用 `python -m pip install ...`，不要用裸 `pip`。

**Q：第一次转写字幕怎么这么久？**
两件事叠在一起：① 首次要下载 464MB 模型；② CPU 上转写接近实时速度。10 分钟口播第一次等几分钟是正常的，同一条片子第二次有缓存。

**Q：字幕识别有错别字？**
默认用 `small` 模型（中文性价比拐点），专有名词和同音字会错（实测「剪短」→「简短」、「划走」→「化走」）。要更准就在字幕设置里换 `medium`（约 1.5GB，慢 3–4 倍）。
另外可以导入自己校对过的 SRT 覆盖自动转写。

**Q：成片里字幕位置/换行和 PR、剪映里看到的不一样？**
成片的换行是程序按 1080 宽自己算的（libass 不会给中文折行）；精调包里的 `字幕.srt` 不折行，交给下游软件按自己的宽度重排。两边看起来不同是有意的，不是 bug。

**Q：点「按时间轴出片」报错说没有字幕数据？**
面板上开了字幕但还没转写/导入 SRT 时会这样拦住（故意的，避免静默出一部没字幕的片子）。点「自动转写」或导入 SRT 即可。
「AI 粗剪 / 口播」不受影响——它会自己转写，转不出来就降级出片并在状态栏说明，不会卡住。

**Q：Windows 上双击 `启动程序.bat` 弹出「pythonw.exe not found」？**
说明没建虚拟环境，或者脚本找不到 Python。先按[安装](#安装)建 `.venv`；脚本会优先用 `.venv\Scripts\pythonw.exe`，找不到才退回系统 PATH。

**Q：处理完的视频在哪？**
`projects/output/`。原始素材不会被改动。

## 项目结构

只列仓库里真实存在的文件（`models/` `bin/` `music/` `projects/` 都是**运行时生成或不入库**的）。

```
ai-film-editing/
├── main.py                     # 入口：web（默认）/ gui / analyze
├── requirements.txt            # 依赖（必需 / 可选分组，带注释）
├── config.json                 # 【运行时生成】大模型配置，含 key，已 gitignore
├── 启动程序.bat                # 【Windows 可选】后台启动，无控制台
├── 调试启动.bat                # 【Windows 可选】带控制台启动
├── backend/
│   ├── server.py               # Flask 服务 + 任务队列 + 分析结果缓存 + 路由
│   ├── ai_analyzer.py          # 镜头/静音/重复/静止/黑场 一次遍历检测
│   ├── autocut.py              # AI 粗剪决策引擎（三档力度 + 按句切）
│   ├── renderer.py             # 渲染成片（ffmpeg 管线为主，moviepy 兜底）
│   ├── exporter.py             # 精调包：EDL / CSV / SRT / 分段素材
│   ├── video_processor.py      # 视频信息 / 抽帧
│   ├── subtitle.py             # faster-whisper 转写 + ASS 字幕生成 + 时间映射
│   ├── speech_cut.py           # 语气词 / 重说 检测（纯函数，零依赖）
│   ├── audio_fx.py             # BGM / 音量归一 / 降噪 / 侧链闪避
│   ├── pacing.py               # 转场编排、片头片尾淡入淡出、镜头节奏
│   ├── beat.py                 # 卡点混剪（音乐节拍对齐）
│   ├── director.py             # 对话式剪辑：需求解析（规则 + 可选大模型）
│   └── style_copier.py         # 参考风格提取（算法已有，未接界面）
├── web/                        # 前端（原生 HTML/CSS/JS，无构建步骤）
│   ├── index.html
│   ├── style.css
│   ├── app.js                  # 时间轴、AI 粗剪流程、效果页、精调包导出
│   ├── icon.ico                # 应用图标
│   └── icon.png
├── gui/
│   └── app.py                  # 旧版 Tkinter 界面（兜底）
├── utils/
│   ├── ffmpeg_setup.py         # ffmpeg 三层定位与 PATH 注入
│   └── downloader.py           # yt-dlp 下载（库已就绪，界面未接）
├── test_*.py                   # 各模块测试（合成素材，不依赖网络）
├── progress.md                 # 开发进度与决策记录（比 README 详细）
└── 项目规划.md                  # 早期规划（以 progress.md 为准）
```

**运行时生成、不入库**：

| 目录 | 内容 |
|---|---|
| `models/whisper/` | faster-whisper 模型（首次用字幕时下载，464MB） |
| `projects/output/` | 成片、精调包 |
| `projects/cache/` | 转写缓存（换片或换模型档位自动失效） |
| `music/` | 音乐库（你自己导入的 BGM） |
| `bin/` | 想用自带 ffmpeg 时把 `ffmpeg.exe` 放这儿，可选 |

## HTTP 接口

本地服务默认跑在 `127.0.0.1:8756`，只监听回环地址。

| 接口 | 说明 |
|------|------|
| `GET /api/info?path=` | 视频基础信息 |
| `GET /api/filmstrip?path=&count=` | 时间轴胶片条缩略图 |
| `GET /api/video?path=` | 带 Range 的视频流 |
| `POST /api/autocut` | **一键粗剪**（分析 + 决策 + 渲染 + 效果），入参 `path` / `strength` / `effects` / `speech` |
| `POST /api/analyze` | 只分析，不渲染 |
| `POST /api/render` | 按指定区间渲染（手动流程） |
| `POST /api/direct` | 对话式剪辑：一句话需求 → 剪辑方案 |
| `POST /api/export-kit` | 导出精调包 |
| `GET /api/job/<id>` | 查询任务进度 / 结果 |
| `POST /api/job/<id>/cancel` | 取消任务 |
| `POST /api/open` | 打开成片或所在文件夹 |
| `POST /api/pick` | 打开系统文件选择框 |
| `GET /api/subtitle/status` | 字幕模型状态 |
| `POST /api/subtitle/transcribe` | 转写 |
| `POST /api/subtitle/parse` · `/save` | SRT 导入 / 导出 |
| `GET /api/bgm/list` · `/audio` | 音乐库列表 / 试听 |
| `POST /api/bgm/add` · `/import` · `/upload` · `/delete` · `/reveal` | 音乐库增删 |
| `GET` / `POST /api/settings` · `POST /api/llm-test` | 大模型配置与连通测试 |
| `GET /api/ping` | 前端心跳（12 秒没心跳服务自动退出） |

## 能力清单

按 `progress.md` 如实记录：勾掉的都有测试或实测记录；**只在合成素材上验过、没拿真人素材跑过的，单独列在下面**，不混在已完成里。

### 已完成

- [x] AI 自主决策粗剪，一键出片（保守 / 标准 / 紧凑三档）
- [x] 镜头 / 静音 / 重复 / 死时间 / 黑场 五类判断依据 + 每条决策写明理由
- [x] 精调包导出（EDL + CSV + 分段素材 + SRT）
- [x] 分析结果缓存，换档重剪不用重扫全片
- [x] 时间轴手动拖拽调整（新建 / 微调 / 平移 / 停用 / 删除）
- [x] **本地语音转写**（faster-whisper，CPU int8，模型落 `models/whisper/`）
- [x] **语音级剪辑**：语气词（三档词表）、重说检测（跨句 / 句内）、三条防误剪 + 总量保护
- [x] **按句切**：句界压 0.2s、句中卡壳留 0.55–0.65s 换气口、剪点避让词边界
- [x] **字幕**：自动转写、断句、SRT 导入导出、字号/位置/描边色/底框可调
- [x] **逐字点亮**（libass `{\kf}`），变速/转场/跨剪切点后仍对齐；无词时间戳时自动降级不假装
- [x] **竖屏 9:16**（模糊背景 / 居中裁切），与字幕烧录合并成一次编码
- [x] **轻降噪**（highpass + afftdn），只压人声原音轨
- [x] **口播预设**：一键设六项，一次出片不用跑两遍
- [x] BGM（音乐库窗口 / 侧链闪避 / 音量归一 loudnorm -16 LUFS）
- [x] 变速（整体 + 区间）、9 种转场 + 自动按镜头差挑选、片头片尾淡入淡出
- [x] 每处硬切剪口 6ms `afade`，消「啵」声
- [x] 对话式剪辑（规则解析 + 可选大模型）、与面板双向同步
