# AI 智能剪辑工具

本地运行的 AI 视频粗剪工具。选中素材点一下，它会自己判断该剪掉哪些部分，
渲染出成片，并导出一份能拿到剪映、Premiere、DaVinci 里继续调整的工程包。

全程在本机完成：视频不上传，语音转写也用本地模型，不联网。

## 功能

### AI 粗剪

一次跑完「分析 → 决策 → 渲染」，直接出成片。三档力度可选：保守、标准、紧凑。

判断依据有五类：

| 类型 | 判断方式 | 处理 |
| --- | --- | --- |
| 静音 | 音轨电平低于阈值且持续够久 | 两端留气口，只剪中间 |
| 重复 | 抽样帧高度相似且间隔较远 | 整段剪掉 |
| 死时间 | 画面几乎不动且没有声音 | 保留开头，压掉后面拖时间的部分 |
| 黑场 / 白场 | 整帧方差极低、亮度极端 | 全部剪掉 |
| 纯色画面 | 方差低但亮度正常 | 只在很短时作为转场剪掉 |

每条决策都会写明理由，可以在界面里逐条查看。

### 口播专项

一个开关同时设好六项：标准力度、剪口头禅、剪重说、开字幕、硬切转场、音量归一。
一次出片就带字幕，不需要先粗剪再回效果页重来一遍。

### 语音级剪辑

本地转写之后按内容剪，而不是只看波形：

- 语气词（嗯、呃、那个、就是）
- 说错重来的前一遍
- 句内重复

按句切时，句界压得更紧、句中卡壳留换气口，剪点会避让词边界。

### 字幕

本地转写自动生成，字号、位置、颜色、描边色、底框可调，支持逐字点亮，
可导入导出 SRT。

没有词级时间戳时（比如导入的外部 SRT），逐字点亮自动降级为整句显示，不会错位。

### 画面与声音

- **竖屏 9:16**：模糊背景（默认，不裁掉画面）或居中裁切，输出 1080×1920
- **BGM**：音乐库选择，侧链闪避，音量归一
- **变速**：整体变速或指定区间，不变调
- **转场**：9 种，可按镜头差异自动挑选
- **淡入淡出**：片头片尾独立可调
- **降噪**：轻度压制口腔杂音，只作用于人声原音轨

### 精调包

导出内容包括：

- `timeline.edl`：剪辑决策表
- `剪辑清单.csv`：逐段清单
- `clips/clip_XX.mp4`：分段素材，原分辨率原音轨
- `字幕.srt`：按成片时间对齐的字幕

导入剪映或 Premiere 后可直接继续精修。

### 对话式剪辑

在对话框里描述需求，例如「剪成 60 秒的卡点混剪，开头 3 秒不要」，
解析成剪辑意图后出片，并回一条「我听懂了什么」。

可接入大模型提升理解能力，不接也能用规则解析。

## 运行环境

| 项目 | 要求 |
| --- | --- |
| Python | 3.10 及以上，推荐 3.11（开发环境为 3.11） |
| FFmpeg | 不强制手动安装，见下方说明 |
| 磁盘 | 代码与依赖约 550 MB；语音模型首次下载约 464 MB；处理视频时另需原片 2–3 倍空间 |
| 内存 | 建议 8 GB 以上 |
| 系统 | Windows、macOS、Linux |

### FFmpeg 的来源

程序启动时按以下顺序查找，命中即用：

1. 项目内 `bin/ffmpeg.exe`
2. 系统 `PATH` 中的 `ffmpeg`
3. `imageio-ffmpeg` 自带的二进制

第三种由依赖清单保证，因此 `pip install` 之后一定有一份可用的 FFmpeg。
想指定自己的版本，装到 `PATH` 里或放进 `bin/`。

## 安装

```bash
git clone https://github.com/m-1229/ai-film-editing.git
cd ai-film-editing

python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

依赖清单不含 `torch` 和 `transformers`，整套装完约 550 MB。

## 启动

```bash
python main.py
```

服务默认监听 `127.0.0.1:8756`，并自动打开一个独立应用窗口。

其他入口：

| 命令 | 用途 |
| --- | --- |
| `python main.py web <端口>` | 指定端口启动 |
| `python main.py analyze <视频路径>` | 只分析，不开界面，打印剪辑建议 |
| `python main.py gui` | 旧版 Tkinter 界面 |
| `python main.py --help` | 查看命令行用法 |

## 首次运行

第一次使用字幕或口头禅功能时，会下载语音模型：

- 模型为 `faster-whisper` 的 small 档，下载后存放在 `models/whisper/`，约 464 MB
- 默认使用国内镜像 `hf-mirror.com`，海外网络可设置环境变量
  `HF_ENDPOINT=https://huggingface.co`
- 下载期间进度只显示整体提示，没有细粒度百分比，属正常现象
- 下载一次后即可离线使用

只做普通粗剪、不使用字幕和口头禅时，不需要下载模型。

首次转写一部十分钟的素材，在 CPU 上需要数分钟。同一素材再次剪辑会复用缓存。

## 项目结构

```text
.
├── main.py              # 入口：web（默认）/ analyze / gui
├── backend/
│   ├── server.py        # HTTP 服务、任务队列、结果缓存
│   ├── ai_analyzer.py   # 镜头、静音、静止、重复、黑场检测
│   ├── autocut.py       # 粗剪决策（三档力度）
│   ├── speech_cut.py    # 语气词、重说、按句切
│   ├── subtitle.py      # 转写、断句、ASS 生成与烧录
│   ├── renderer.py      # FFmpeg 渲染管线
│   ├── pacing.py        # 转场与节奏
│   ├── audio_fx.py      # 音量归一、降噪、混音
│   ├── exporter.py      # 精调包导出
│   ├── director.py      # 对话式剪辑
│   └── style_copier.py  # 参考风格提取
├── web/                 # 前端（原生 HTML / CSS / JS）
├── utils/               # FFmpeg 定位、视频下载
└── gui/                 # 旧版 Tkinter 界面
```

`models/`、`bin/`、`music/`、`projects/` 为运行时目录，不纳入版本库。

## 已知限制

- 观感类结论（逐字点亮跟不跟得上语速、降噪能否压住呼吸声）主要在合成素材上验证，
  真实录音的听感尚未系统验证
- 转场与画幅判定的阈值在合成素材上标定，真实素材可能需要微调
- 语义级判断（例如「只保留讲产品的那几段」）尚未实现
- 风格模仿算法已具备，但未接入界面
- 在线视频下载能力已具备，但未接入界面
